# AI for Work and Study

A simple, curated directory of useful AI tools for work, study, research, writing, presentations, meetings, productivity, and everyday tasks.

## What is AI for Work and Study?

**AI for Work and Study** is a lightweight micro-directory that helps people discover useful AI tools without having to search through complicated or overwhelming lists.

Tools are manually reviewed and organised around practical tasks and common use cases.

The goal is simple: **make useful AI tools easier to discover and understand.**

## Pages

* **Home** — Browse and search the full collection of AI tools
* **Students** — AI tools for studying, research, writing, notes, presentations, and productivity
* **Work** — AI tools for writing, research, meetings, productivity, automation, and everyday work

## Features

* 🔎 Search tools by name, task, or benefit
* 🧰 Curated AI tools for practical work and study needs
* 🎓 Dedicated student tools page
* 💼 Dedicated work tools page
* 📱 Mobile-friendly design
* 🌙 Clean, minimal interface
* 🔗 Links to official tool websites
* 🆓 Free access options are clearly indicated
* 🔐 Privacy-focused and local tools are highlighted when relevant

## Featured Projects

### LocalFlow

The current version includes a **PDF to Text Converter** that processes PDF files locally without uploading them to a cloud service.

**Project:** https://github.com/ai-directory669/localflow

### UTM Tag Builder

## Why this project?

Many AI directories contain large numbers of tools but provide little context about what each tool is actually useful for.

This project focuses on keeping the directory:

* Simple
* Practical
* Easy to browse
* Focused on real work and study use cases

## Important Note

AI tools, pricing, free plans, and available features can change over time.

Please check the official website of each tool for the latest information before relying on any specific feature or pricing information.
