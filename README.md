# AI for Work and Study

A simple, curated directory of useful AI tools for work, study, research, writing, presentations, meetings, and productivity.

## What is AI for Work and Study?

AI for Work and Study is a lightweight micro-directory designed to help people discover useful AI tools without having to search through complicated lists.

The tools are manually reviewed and organised by common tasks and use cases.

## Pages

- **Home** — Browse and search the full collection of AI tools
- **Students** — AI tools for studying, research, writing, notes, presentations, and productivity
- **Work** — AI tools for writing, research, meetings, productivity, automation, and everyday work

## Features

- 🔎 Search tools by name, task, or benefit
- 🧰 Curated AI tools for common work and study needs
- 🎓 Dedicated student tools page
- 💼 Dedicated work tools page
- 📱 Mobile-friendly design
- 🌙 Clean, minimal interface
- 🔗 Links to official tool websites
- 🆓 Free access options are clearly indicated

## Why this project?

Many AI directories contain large numbers of tools without clearly explaining what they are useful for.

This project focuses on keeping the directory simple, practical, and easy to browse.

## Important Note

AI tools, pricing, free plans, and available features can change over time. Please check the official website of each tool for the latest information.
